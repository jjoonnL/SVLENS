# Private input layout

`<PRIVATE_ROOT>` is a directory outside this code repository. Only the schema is public; data and generated results are not.

```text
<PRIVATE_ROOT>/
├── Gene_ref/gencode.v49.basic.annotation.gtf.gz
├── SV_association/NFE/qtbig.A/<TRAIT>_adjAgeSexYobPC_InvNorm.txt.gz
├── results/                              # generated by SV scripts
│   ├── gene_table.parquet
│   ├── <TRAIT>/sv_weighted.parquet
│   └── sv_pleiotropy/
└── results_server/step27_full_rare_snv_gene_body_all_traits/  # imported SNV outputs
```

SV gzip TSVs require `Chrom`, `Pos`, `Name`, `effectAllele`, `effectAlleleFreq`, `pval`, `Beta`, `SE`, `N`, and `info`. `Pos` is 1-based; exact `Name` identifiers are used for cross-trait recurrence. `gene_table.parquet`, generated from GENCODE v49 basic, contains `chrom`, `gene_start`, `gene_end`, `strand`, `gene_id`, `gene_name`, `tss`, `promoter_start`, and `promoter_end`. Gene-body intervals are 0-based half-open; promoter/CDS/UTR features classify variants after membership, not extend the membership window.

Rare-SNV input to `06_snv_acat.py` is `<SOURCE>/<GCST_ID>.tsv.gz` under `--gwas-dir`. Each TSV requires `chromosome`, `base_pair_location`, `effect_allele`, `other_allele`, `p_value`, `effect_allele_frequency`, and `n`; position is 1-based. The script audits exact phenotype matches (63 mapped, 14 unavailable) and writes one trait directory plus `step27_full_rare_snv_audit.csv`. Downstream convergence requires variant schema `biallelic_snv_primary_plus_lt50bp_indel_gene_body_v2` and membership `GENCODE_v49_gene_body_0_based_half_open`. Do not use the superseded promoter-window cache.
